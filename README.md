# サポートコール（Support Call App）

## 概要

「サポートコール」は、入院患者さんが看護師ではなく、看護助手・サポートスタッフへ依頼したい内容を簡単に伝えるためのアプリです。

患者さんがスマートフォンやタブレットから依頼内容を選択し、スタッフ側で依頼内容を確認・対応できる仕組みを想定しています。

看護現場では、看護師が専門的な看護業務だけでなく、買い物・環境整備・物品整理など、看護助手でも対応できる依頼を受けることがあります。

このアプリでは、そのような依頼をサポートスタッフへ直接つなぐことで、看護師と看護助手の業務分担を支援することを目的としています。

## 主な機能

### 患者用画面

患者さんは部屋番号を入力し、依頼したい内容を選択できます。

現在選択できる依頼内容は以下です。

- 買い物（売店へ買い物に行ってほしい）
- 掃除をしてほしい
- お風呂の準備をしてほしい
- ゴミを捨ててほしい
- 電気がつかない
- 物を探してほしい
- トイレを片付けてほしい
- 家族に電話してほしい
- シーツ交換をしてほしい
- その他

依頼後は「サポートナースに依頼しました」と表示されます。

スタッフが対応を終了すると、患者用画面にも対応した日時が表示されます。

### スタッフ用画面

スタッフ側では患者さんから届いた依頼を一覧で確認できます。

主な機能は以下です。

- 部屋番号の確認
- 依頼内容の確認
- 依頼日時の確認
- 「確認する」による受付
- 「対応終了」による完了処理
- 対応中の依頼一覧
- 対応履歴の確認
- 対応終了日時の記録
- カレンダーから過去の対応履歴を確認

## 利用イメージ

```text
患者
 ↓
スマートフォン・タブレット
 ↓
依頼内容を選択
 ↓
サポートスタッフへ依頼
 ↓
スタッフが内容を確認
 ↓
対応
 ↓
対応終了
 ↓
患者画面へ対応完了日時を表示
```

## このアプリで目指していること

このアプリの目的は、単に患者さんからスタッフを呼ぶことではありません。

患者さん自身が「何をお願いしたいのか」を選択してから依頼することで、スタッフが事前に内容を把握できる仕組みを目指しています。

これにより、以下の実現を想定しています。

- 看護師と看護助手の役割分担
- スタッフの移動や確認作業の削減
- 患者さんの待ち時間の短縮
- 依頼内容・対応時間の記録
- 病棟業務の可視化

## 現在の開発状況

現在はプロトタイプ版です。

ブラウザ上で、**患者から依頼 → スタッフが確認 → 対応終了 → 履歴確認**という一連の流れを確認できます。

現在のブラウザ版では、依頼情報を `localStorage` に保存しています。

そのため、同じブラウザ内ではデータを確認できますが、別のスマートフォンやPCへリアルタイムに依頼を送信する機能は、今後サーバー側の仕組みを実装する予定です。

## 今後追加したい機能

- 患者端末とスタッフ端末間でのリアルタイム共有
- データベースへの依頼履歴保存
- スタッフ端末への通知
- 未対応・対応中・対応済みの管理
- 患者画面への受付状況表示
- スタッフごとの対応記録
- 病棟ごとの依頼管理
- 日別・月別の依頼件数集計
- よく依頼される内容の分析

## 開発の背景

看護現場では、人手不足が続く中で、看護師が本来の看護業務以外のさまざまな依頼にも対応しています。

看護師として勤務した経験から、**「看護師でなくても対応できる依頼を、適切なスタッフへ直接つなぐことができないか」**と考えたことが、このアプリを制作するきっかけです。

医療現場の業務をITで少しでも効率化することを目指して制作しています。
